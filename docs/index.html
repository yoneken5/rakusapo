何をするアプリか

らくサポは、あおぞら保険サービス社員向けの日報入力支援です。ブラウザで開き、話した内容（または打ち込んだ内容）を日報テンプレート（決まった見出しの文面）に整理します。できあがった文をコピーして、今使っている日報へ貼ります。 出典: らくサポ README（社員向け説明）

らくサポは提出先を置き換えません。入口だけを軽くします。日報本文はアプリに保存しません。ログインも不要です。

社員向けの共有先は https://rakusapo.streamlit.app/ です。ブラウザで開くだけで使え、ログインは不要です。iPhoneでは青い「録音を開始」から文字化できます。

操作は3つだけ

画面の見出しどおりです。選ぶ、話す、確認してコピーする。

1
種類を選ぶ

損保更改・損保新規・生保新規・生保アフター・苦情対応。型が違うので、先に選びます。

2
話す・書く

番号つきで話すか、欄に直接入力。「1.自動車、9月30日、対面」のように、番号が棚の番地になります。

3
確認してコピー

「日報テンプレートを生成」のあと、文面を直してコピー。足りない所は【要入力】と出ます。

パソコンではマイク録音か音声ファイル（wav / mp3 / m4a など）も使えます。認識できないときは、同じ欄に手で書けます。

5つの日報の型

保険の現場では、用件ごとに残す項目が違います。らくサポは、この5つを別々の型として持っています。

損保更改

種目・満期日・面談手法、意向の変化、前年差異説明、高齢者対応。

損保新規

新規の損保。更改とは別の見出しに流し込みます。

生保新規

顧客の基本情報、対応概要、ニーズ、提案、反応、次の一手。

生保アフター

契約後のフォロー。新規提案とは項目が違います。

苦情対応

苦情の記録用。営業日報とは棚が別です。種類をまちがえると、見出しがかみ合いません。

番号の話し方（損保更改の例）
1. 自動車、9月30日、対面
2. 変化なし
3. 実施済
4. 該当なし

画面の「番号入力の例」に、選んだ型の目安が出ます。番号が棚のラベルです。

用語は覚える。本文は残さない

音声認識は、保険の専門語をひらがなで拾いがちです。「じゅうせつ」を「重要事項説明」に直すのが、よく使う用語です。

よく使う用語

この端末にだけ覚えます。最初から「じゅうせつ → 重要事項説明」「そんぽ → 損保」などが入っています。追加・編集・削除ができます。

じゅうせつ 重要事項説明
みついすみとも 三井住友
残さないもの
  • 日報本文は保存しない
  • 顧客名は用語に登録しない
  • ログインなし。開いて使う

足りない数字や項目は、生成後に警告や【要入力】で知らせます。生成は止まりません。最後の確認は、コピーする人の仕事です。

裏側は、Pythonの画面づくり

本体ファイルは rakusapo_app.py です。画面は Streamlit（ストリームリット＝Pythonのコードだけでブラウザ画面を作る仕組み）で動きます。 出典: Streamlit 公式 — Get started

起動のイメージ
$ streamlit run rakusapo_app.py
You can now view your Streamlit app
Local URL: http://localhost:8501

社員が触るのは、Streamlit Community Cloud（公式の無料公開先）に載せた画面です。GitHubのプログラムをウェブに出す仕組みで、共有URLを渡せばブラウザから使えます。 出典: Streamlit 公式 — Community Cloud

音声を文字にする処理は、ブラウザや録音データから文字起こし（話し言葉を書き言葉にすること）します。Chrome などではウェブ音声 API が使われることがあります。 出典: MDN — ウェブ音声 API

よくある誤解

誤解: 「押すだけで、何も話さず日報ができる」

実際は:

材料は、話した（または書いた）内容です。話していない満期日は、【要入力】のまま残るのが正しい動きです。

誤解: 「これ自体が会社の日報システム」

実際は:

提出先は今までどおりです。らくサポは清書してコピーするところまで。貼る先は、既存の日報です。

誤解: 「生成したら、確認しなくていい」

実際は:

右側の文面は、送る前に直せます。種類の取り違えや聞き間違いがあり得ます。緑のバッジは「必須が埋まった」合図で、「内容が正しい」保証ではありません。

まとめ — 覚えておきたい3つのこと

01

選ぶ → 話す → コピーして貼る

5つの型から選び、番号で話し、テンプレートを生成して既存の日報へ貼る。提出先は替えません。

02

本文は残さない。用語だけ覚える

顧客名は辞書に入れない。ログインなし。ブラウザで開いて使います。

03

【要入力】は、確認の合図

足りない項目を埋めてからコピーする。秘書の下書きに、自分の目を通すイメージです。

らくサポは「貼る文面」をつくる相棒です。

種類を選び、番号で話し、右の文面を見てコピーする。日報そのものは、これまでどおりの場所に残します。
